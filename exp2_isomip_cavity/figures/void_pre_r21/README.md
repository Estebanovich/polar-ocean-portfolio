# Void results (pre-R21): kept as a record only, not results

Every JSON in this directory comes from runs made before ruling R21 (2026-11-09), when the model computed the friction velocity as u*² = Cd·u² + u_tidal² instead of AD16 Eq. 27, u*² = Cd·(u² + u_tidal²). That was our error (class a; `notes/pd1_config.md`, section «Error (a): forma de u\* (R21)»). The files are the first Γ_T calibration and its 3-point and 4-point evaluations (`calibration_*`, `verify_*`, `pd1_calibration_eval.json`) and the boundary-layer diagnostic series of `notes/pd1_diagnostico_capa_limite.md` (`diag_bl_*`). All of those runs are void: no number here is a result of Experiment 2, none is read by the README, its renderer or any figure script, and the valid replacements are the `*_r21.json` files one directory up. They are kept so that the record of the error, and of what it changed, can be checked.
